**Type guard patterns for library files:**

Pattern A — rotator.markKeyFailed(apiKey, error.message):
```typescript
// BEFORE:
} catch (error: any) {
    rotator.markKeyFailed(apiKey, error.message);
    console.error(`[Provider] Failed:`, error.message);
    return null;
}

// AFTER:
} catch (error: unknown) {
    const errMsg = error instanceof Error ? error.message : String(error);
    rotator.markKeyFailed(apiKey, errMsg);
    console.error(`[Provider] Failed:`, errMsg);
    return null;
}
```

Pattern B — console.error + return []:
```typescript
// BEFORE:
} catch (error: any) {
    console.error('[NVD] Fetch error:', error.message);
    return [];
}

// AFTER:
} catch (error: unknown) {
    console.error('[NVD] Fetch error:', error instanceof Error ? error.message : String(error));
    return [];
}
```

Pattern C — throw new Error with message:
```typescript
// BEFORE:
} catch (error: any) {
    console.error('[GitHub] Failed to fetch:', error.message);
    throw new Error('Failed to fetch from GitHub');
}

// AFTER:
} catch (error: unknown) {
    console.error('[GitHub] Failed to fetch:', error instanceof Error ? error.message : String(error));
    throw new Error('Failed to fetch from GitHub');
}
```

Pattern D — conditional on error.status:
```typescript
// BEFORE:
} catch (error: any) {
    if (error.status === 404) {
        return null;
    }
    console.error(`[GitHub] Failed to get path:`, error.message);
    return null;
}

// AFTER:
} catch (error: unknown) {
    if (error instanceof Object && 'status' in error && error.status === 404) {
        return null;
    }
    console.error(`[GitHub] Failed to get path:`, error instanceof Error ? error.message : String(error));
    return null;
}
```

Each replacement must:
1. Change `error: any` to `error: unknown`
2. Guard every `.message` access
3. Guard `.status` and other property accesses appropriately
4. For `console.error('msg:', error)` — bare `error` is fine without a guard
