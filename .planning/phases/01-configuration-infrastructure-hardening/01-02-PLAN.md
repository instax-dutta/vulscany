    **Step B:** After the codemod (or manual rename), rewrite `src/proxy.ts` completely with:

    1. **Import:** `import { NextRequest, NextResponse } from 'next/server'`
    2. **Rename export:** `export function proxy(request: NextRequest)` (not `middleware`)
    3. **Nonce generation:** `const nonce = Buffer.from(crypto.randomUUID()).toString('base64')`
    4. **Environment check:** `const isDev = process.env.NODE_ENV === 'development'`
    5. **CSP directives (per RESEARCH.md lines 279-291):**
       - `default-src 'self'`
       - `script-src 'self' 'nonce-{nonce}' 'strict-dynamic'` — add `'unsafe-eval'` ONLY when `isDev` is true
       - `style-src 'self' 'nonce-{nonce}'`
       - `img-src 'self' blob: data: https:`
       - `font-src 'self' data:`
       - `connect-src 'self' https://api.github.com` — NO `*.upstash.io` (satisfies REQ-5)
       - `object-src 'none'`
       - `base-uri 'self'`
       - `form-action 'self'`
       - `frame-ancestors 'none'`
       - `upgrade-insecure-requests`
       - Do NOT include `unsafe-inline` anywhere (per CSP spec, nonces are ignored if unsafe-inline is present)
       - Do NOT include `X-XSS-Protection` anywhere (deprecated, per RESEARCH.md)
    6. **Set x-nonce header:** Create `requestHeaders` from `request.headers`, set `'x-nonce'` header
    7. **Create response:** `NextResponse.next()` with modified request headers
    8. **Set CSP on response:** `response.headers.set('Content-Security-Policy', cspDirectives.join('; '))`
    9. **Auth check (unchanged from middleware):** If `request.nextUrl.pathname.startsWith('/dashboard')`, check cookie `github_token`, redirect to `/` if missing
    10. **Return response**
    11. **Matcher config:** Expand to cover all routes:
        ```typescript
        export const config = {
          matcher: ['/((?!_next/static|_next/image|favicon.ico|.*\\.png$).*)'],
        }
        ```
        (Was `['/dashboard/:path*', '/api/:path*']` — expand coverage so CSP nonces are applied to HTML page requests too.)

    **Step C:** Delete `src/middleware.ts` (both files cannot coexist — Next.js 16 build error per Pitfall 3 in RESEARCH.md).

    Key constraints:
    - Static security headers (X-Frame-Options, X-Content-Type-Options, Referrer-Policy, HSTS, Permissions-Policy) are NOT set in proxy.ts — they belong in next.config.ts (Task 3 of this plan). RESEARCH.md Anti-Patterns confirms: "Setting static headers in proxy.ts adds unnecessary runtime overhead."
    - Auth cookie check stays in proxy.ts (it's dynamic per-request).
    - Use `crypto.randomUUID()` (Node.js built-in) — no polyfills or libraries needed.
  </action>
